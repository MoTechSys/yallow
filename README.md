## ✨ المميزات التقنية

### 📱 تجربة الهاتف (الأولوية الأولى)
- **Mobile-first CSS** — كل شيء مصمم للهاتف أولاً ثم يتوسّع
- **Dock سفلي بستايل التطبيقات** — 5 أزرار، زر واتساب بارز نابض، يختفي عند التمرير للأسفل ويعود عند الصعود
- **Side Drawer فاخر** — قائمة جانبية منزلقة بأيقونات ذهبية وأوصاف، تُغلق بالسحب (Swipe) أو بالضغط خارجها أو بـ Escape
- **صورة Hero مخصصة 9:16** للهاتف عبر `<picture>`، وأخرى 16:9 للديسكتوب
- **Safe-area insets** لهواتف النوتش، أهداف لمس 44–56px، اهتزاز خفيف (Haptics) عند الضغط
- **لا تمرير أفقي** — `scrollWidth === viewport` مُتحقق منه آلياً

### 🎥 الطبقة السينمائية (Three.js + Canvas)
| المؤثر | الوصف |
|---|---|
| **شعار ذهبي 3D حقيقي** | درع + تاج بجواهر + سيفان متقاطعان + جوهرة حمراء شفافة + حلقتان مداريتان، بمواد PBR (Clearcoat + Transmission) وإضاءة بيئية. يتبع الماوس/الإصبع، ويستجيب لـ **الجيروسكوب** على الهاتف. **اضغط عليه**: دوران انفجاري + 70 شظية جواهر تتطاير + وميض ذهبي + اهتزاز الشاشة + Haptic |
| **انتقال واتساب السينمائي** | عند ضغط أي زر واتساب: موجة خضراء من نقطة الضغط ← إظلام ← حلقتان تُرسمان (ذهبية + خضراء) ← الشعار يقفز ← نص يُكتب كلمة-بكلمة ← وميض + 260 جزيئاً ذهبياً ← يفتح واتساب ← خروج ناعم. زر "تخطّي" متاح |
| **ستارة افتتاحية** | بعد اللودر تنشق الشاشة نصفين بخط ذهبي متوهج يتوسّع كشعاع |
| **Torch Reveal (غموض)** | شبكة سداسية ذهبية مخفية في الهيرو تظهر فقط حول إصبعك/مؤشرك كأنك تحمل مشعلاً |
| **Gold Wipe** | عند التنقل بين الأقسام: مسحة ذهبية بالشعار تغطي الشاشة ثم تنسحب |

> Three.js مضمّن محلياً في `assets/vendor/` (لا CDN). الشعار 3D يتوقف تلقائياً خارج الشاشة أو عند إخفاء التبويب، ويُعطَّل بالكامل مع `prefers-reduced-motion`.

### 🧩 مكوّنات وظيفية
- **QR رسمي** — يفتح محادثة واتساب مباشرة، بألوان ذهبية ونقاط مدوّرة وشعار في المنتصف. **مُتحقق من قراءته بـ OpenCV** (Error Correction H)
- **نسخ الرقم** بضغطة مع Toast تأكيد
- **مشاركة الموقع** عبر Web Share API (يتراجع إلى نسخ الرابط)

- **Scroll-spy** يفعّل الرابط الحالي في الهيدر والـ Dock
- **FAQ** بـ `<details>` أصلي وأيقونة + تدور إلى ×

### 📦 PWA
- `manifest.webmanifest` — اسم، أيقونات 192/512/maskable، اختصار واتساب، `display: standalone`
- `sw.js` — Service Worker يخزّن الأصول الأساسية للعمل دون اتصال (يُسجَّل على HTTPS فقط)
- `apple-mobile-web-app-*` meta tags لـ iOS

### 🔍 SEO والمشاركة
- `<title>` و `description` و `keywords` بالعربية
- **Open Graph** + **Twitter Card** مع صورة مشاركة مخصصة `og.jpg` (1200×630)
- `theme-color`، `lang="ar"`، `dir="rtl"`
- بنية عناوين دلالية (`h1` → `h2` → `h3`)

## 🎨 التخصيص

### تغيير رقم الهاتف
ابحث واستبدل في `index.html` و `sw.js` و `manifest.webmanifest`:
```
967770941666        → الرقم الجديد بدون + أو مسافات (لروابط wa.me و tel:)
+967 770 941 666    → الرقم الجديد بالتنسيق المعروض
```
ثم أعِد توليد QR (انظر أدناه).

### إعادة توليد رمز QR
```bash
pip install qrcode pillow
python3 - <<'EOF'
import qrcode
from PIL import Image, ImageDraw
qr=qrcode.QRCode(error_correction=qrcode.constants.ERROR_CORRECT_H, box_size=12, border=2)
qr.add_data("https://wa.me/967770941666"); qr.make(fit=True)
m=qr.get_matrix(); n=len(m); box=12; size=n*box
img=Image.new('RGBA',(size,size),(0,0,0,0)); d=ImageDraw.Draw(img)
for y in range(n):
    for x in range(n):
        if m[y][x]:
            t=(x+y)/(2*n); c=(int(245-88*t),int(215-99*t),int(138-106*t),255)
            d.rounded_rectangle((x*box,y*box,(x+1)*box-1,(y+1)*box-1),radius=2,fill=c)
cx=size//2; r=int(size*0.09); d.rectangle((cx-r,cx-r,cx+r,cx+r),fill=(0,0,0,0))
img.save('assets/img/qr-whatsapp.png',optimize=True)
EOF
```

## ⚡ الأداء والوصولية

### الأداء
- صور **WebP** مع JPEG fallback عبر `<picture>` (توفير ~50%)
- `preload` لصورة الهيرو المناسبة للجهاز فقط (`media` attribute)
- `loading="lazy"` لصور الخدمات، `fetchpriority="high"` للهيرو
- Canvas الجزيئات يتوقف عند `document.hidden` ويحترم DPR (حد أقصى 2×)
- كل الأنيميشن على `transform`/`opacity` فقط (GPU-composited)
- `will-change` موضوع بحذر على العناصر المتحركة فقط
- JS واحد `defer`، CSS واحد، صفر تبعيات خارجية عدا Google Fonts

### الوصولية
- `prefers-reduced-motion` — يعطّل كل الأنيميشن والمؤشر المخصص
- `aria-label` / `aria-expanded` / `aria-hidden` على القائمة والأزرار
- `role="tablist"` / `role="tab"` على تابات السياسة
- `role="status"` + `aria-live="polite"` على Toast
- تباين ألوان مرتفع (ذهبي فاتح على كحلي داكن)
- أهداف لمس ≥ 44px في كل مكان
- `<details>/<summary>` أصلي للأسئلة (يعمل بلا JS)
- `scroll-padding-top` يمنع اختفاء العناوين خلف الهيدر الثابت

## ❓ الأسئلة الشائعة للمطوّر

**لماذا لا توجد أسعار في الموقع؟**
لأن أسعار الشدات تتغير يومياً حسب السوق. كل زر "اطلب السعر" يفتح واتساب برسالة جاهزة تتضمن الباقة. يمكن إضافة أسعار ثابتة بسهولة (انظر التخصيص).

**تدفق النشاط الحي — هل هو حقيقي؟**
لا، هو محاكاة بصرية (Social proof) بأسماء ومدن عشوائية. لربطه بمصدر حقيقي، استبدل دالة `mk()` في `main.js` بطلب `fetch` لـ API.

**لماذا الكلمات وليس الحروف في أنيميشن العنوان؟**
تقسيم العربية إلى حروف منفصلة يكسر الاتصال بين الحروف (الحروف المتصلة تصبح منفصلة). التقسيم على مستوى الكلمة يحافظ على شكل الخط.

**كيف أُجبر المتصفح على تحميل التحديثات بعد النشر؟**
غيّر اسم الكاش في `sw.js` (`abu-tariq-v1` → `v2`). الـ SW الجديد سيحذف الكاش القديم عند التفعيل.

**هل يعمل بدون JavaScript؟**
نعم جزئياً: كل المحتوى والروابط والـ FAQ تعمل. الأنيميشن والقائمة الجانبية والتابات تحتاج JS.
