# متجر أبو طارق — الموقع الرسمي

موقع ترويجي فاخر (Landing Page) لـ **متجر أبو طارق لبيع حسابات ببجي موبايل** في اليمن.

## الخدمات المعروضة
| الخدمة | سياسة التعامل |
|---|---|
| بيع حسابات ببجي موبايل | الاستلام قبل الدفع + ضمان رسمي 15 يوماً |
| شحن الشدات (UC) | الدفع قبل الشحن — باقات 60 / 325 / 660 / 1800 / 3800 / 6600 |
| شراء بدلات إكس (X-Suit) | الدعم قبل الشراء |
| توصيل الأموال مباشرة | خدمة مالية مصاحبة |

## التواصل
- واتساب / اتصال: **+967 770 941 666**
- التغطية: الحديدة • المكلا • حضرموت • جميع محافظات اليمن

## التقنيات
- HTML5 / CSS3 / Vanilla JS (بدون أي إطار عمل)
- تصميم Dark-Gold فاخر، RTL بالكامل، متجاوب مع الجوال
- خطوط Cairo + Tajawal من Google Fonts
- تأثيرات: جزيئات ذهبية (Canvas)، Reveal on Scroll، عدّادات، Parallax
- SEO / Open Graph tags

## التشغيل محلياً
```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```
